# CyberToolkit

CyberToolkit is a modular cybersecurity toolkit developed in Python.

The purpose of this project is to provide practical tools for cybersecurity professionals, students, and anyone interested in learning Python while building useful security utilities.

> 🚧 This project is currently under active development.

---

## Features

### Current

- Password Generator

### Planned

- Hash Generator
- File Hash Checker
- File Encryption / Decryption
- Network Scanner
- Port Scanner
- Ping Utility
- DNS Lookup
- Whois Lookup
- Base64 Encode / Decode
- URL Encoder / Decoder
- System Information
- File Utilities
- Log Analyzer

## Installation

Clone the repository:

```bash
git clone git@github.com:mahsuntanriverdix-eng/CyberToolkit.git
```

Go to the project directory:

```bash
cd CyberToolkit
```

Run:

```bash
python main.py
```
